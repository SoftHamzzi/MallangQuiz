# 🐑 말랑말랑 퀴즈

마크다운으로 정리한 공부 내용을 AI가 매일 퀴즈로 만들어주는 도구입니다.
블로그 포스트를 오래 기억하기 위한 일일 복습 루틴을 자동화합니다.

## 시작 계기

이펙티브 C++, 게임 서버 프로그래밍, 대학 강의 자료 등을 마크다운으로 열심히 정리해도, 시간이 지나면 잊어버립니다.
AI가 없던 시절에는 퀴즈를 직접 만드는 수고 때문에 일일 루틴으로 만들기 어려웠지만, 지금은 다릅니다.

**말랑말랑 퀴즈**는 내 마크다운 포스트를 기반으로 AI가 매일 퀴즈를 생성해줍니다.

## 동작 방식

```
/quiz 입력
  └→ collect.js 실행 (포스트 스캔 + 랜덤 선택 + 이미지 수집)
  └→ wrongnote.js pick 실행 (오답노트에서 재출제할 문제 뽑기)
       └→ Claude Code가 템플릿 읽기 → 포스트 읽기 → 퀴즈 생성 (오답노트 문제는 변형 재출제)
            └→ quiz-output/{날짜시간}/quiz.md + answers.md 생성
```

퀴즈를 직접 풀고 나면 채점도 맡길 수 있습니다.

```
/grade 2026-08-19-260819_mallang_quiz.md 입력
  └→ prepare-grade.js 실행 (문제지 탐색 + 원본 해답지 매칭 + 답안 추출)
       └→ Claude Code가 해답지 + 출처 문서 읽기 → 채점
            └→ 문제지와 같은 폴더에 *_answer.md 생성 (정답 + 해설 + 점수 + 피드백)
       └→ wrongnote.js record 실행 (오답노트 갱신: 신규 등록 / 단계 상승 / 리셋 / 마스터 제거)
```

- **`collect.js` / `prepare-grade.js` / `wrongnote.js`**: 포스트 디렉터리 탐색, 제외 패턴 적용, 이미지 다운로드, 해답지 매칭, 오답노트 저장/조회 등 기계적인 작업
- **Claude Code**: 템플릿 선택, 포스트 내용 분석, 퀴즈 문제 생성(오답노트 변형 포함), 답안 채점 등 지능적인 작업

## 필수 조건

- [Claude Code](https://claude.ai/code) 설치 및 로그인
- Node.js 18 이상

## 설치

```bash
git clone https://github.com/your-username/MallangQuiz.git
cd MallangQuiz
npm install
```

## 설정

`mallang-quiz.config.json`을 수정합니다.

```json
{
  "postsDir": "/absolute/path/to/your/_posts",
  "outputDir": "./quiz-output",
  "excludePatterns": [
    "drafts/**",
    "*.private.md"
  ],
  "quizCount": 5,
  "language": "ko",
  "wrongNote": {
    "enabled": true,
    "ratio": 0.2,
    "maxStage": 2
  }
}
```

| 항목 | 설명 | 기본값 |
|------|------|--------|
| `postsDir` | 마크다운 포스트 폴더 절대 경로 | **(필수)** |
| `outputDir` | 퀴즈 결과 저장 폴더 | `./quiz-output` |
| `excludePatterns` | 제외할 파일 패턴 ([.gitignore 형식](https://git-scm.com/docs/gitignore)) | `[]` |
| `quizCount` | 생성할 문제 수 | `5` |
| `language` | 퀴즈 언어 (`ko` / `en`) | `ko` |
| `wrongNote.enabled` | 오답노트 재출제 기능 사용 여부 | `true` |
| `wrongNote.ratio` | 오답노트에서 채울 문제 비율 (`quizCount`에 곱함, 반올림) | `0.2` |
| `wrongNote.maxStage` | 오답노트에서 제거되기까지 필요한 연속 만점 횟수 | `2` |

## 사용법

Claude Code에서 프로젝트 디렉터리를 열고 슬래시 커맨드를 입력합니다.

```
/quiz
```

## 채점하기

생성된 `quiz.md`를 원하는 곳(예: 블로그 포스트 폴더)에 복사해 직접 풀고 나면, `/grade`로 채점할 수 있습니다.

```
/grade 2026-08-19-260819_mallang_quiz.md
```

파일명만 넘기면 `postsDir` 아래에서 알아서 찾습니다. (경로를 직접 줘도 됩니다.)

동작:

1. 문제지의 **출처 목록**을 대조해 대응하는 `quiz-output/{날짜시간}/answers.md`를 자동으로 찾습니다.
2. 원본 해답지를 **정답의 기준**으로, 각 문제의 출처 문서를 **채점 근거**로 삼아 답안을 평가합니다.
3. 문제지와 같은 폴더에 `*_quiz.md` → `*_answer.md` 이름으로 해답 파일을 만듭니다.
   - Jekyll frontmatter의 `title`은 `... 문제` → `... 해답`으로 바뀌고, 나머지는 그대로 유지됩니다.
4. 채점 결과로 오답노트를 갱신합니다 (만점을 못 받은 문제는 등록/리셋, 오답노트 문제를 만점으로 다시 풀면 단계 상승 — 자세한 내용은 아래 [오답노트](#오답노트-복습-재출제) 참고).

채점 기준:

| 유형 | 배점 (문제당 10점) |
|------|--------------------|
| 객관식 | 정답 10점 / 오답 0점 |
| OX | 판단 7점 + 근거 3점 |
| 빈칸 채우기 | 빈칸 개수로 균등 배분 |
| 서술형 | 핵심 논점별 부분 점수 |

- 표현이 달라도 핵심 개념이 맞으면 정답으로 봅니다.
- 템플릿 플레이스홀더가 그대로거나 "기억이 안 난다" 같은 서술은 **미응답(0점)** 처리됩니다.
- 결과 파일에는 채점 표, 총평, 문항별 피드백, **📌 복습 포인트**(틀린 문제의 출처 링크)가 함께 들어갑니다.

생성된 해답 파일 구조:

```markdown
**총점:** 29.5/50 (59점) 🟡 복습이 필요해요

## 📊 채점 결과

| 문항 | 유형 | 난이도 | 결과 | 점수 |
| --- | --- | --- | --- | --- |
| Q1 | 객관식 | 🟡 보통 | ⭕ 정답 | 10 / 10 |
| Q2 | 서술형 | 🟡 보통 | 🔺 부분 정답 | 3.5 / 10 |
| Q4 | 빈칸 채우기 | 🟢 쉬움 | ⬜ 미응답 | 0 / 10 |
```

## 오답노트 (복습 재출제)

말해보카 같은 어학 앱의 복습 큐에서 착안한 기능입니다. 채점 시 만점을 못 받은 문제는 자동으로 오답노트에 등록되고, 이후 `/quiz`를 실행할 때마다 일정 비율로 섞여 재출제됩니다.

- **문구는 매번 바뀝니다.** 같은 문제를 그대로 복사하지 않고, 같은 출처·같은 개념을 다른 각도로 다시 물어봅니다 (정답 암기가 아니라 이해를 확인하기 위함).
- **연속 2번 만점을 받아야** 오답노트에서 빠집니다. 한 번 맞혀도 다음 복습에서 또 틀리면 처음 상태로 되돌아갑니다.
- quiz.md에서 `📌 오답노트 (N번째 복습)` 배지로 구분되며, 처음 틀린 날짜도 함께 표시됩니다.
- 저장 위치는 `.quiz-wrongnote/wrongnotes.json`이며, `quiz-output/`처럼 `/clear-cache`·`/clear-output`이 건드리지 않습니다.

설계 배경과 상세 규칙은 [docs/wrong-note-plan.md](docs/wrong-note-plan.md)에 정리되어 있습니다.

## 퀴즈 템플릿

`quiz-templates/` 폴더에 문제 형식 템플릿이 있습니다. AI가 포스트 내용에 맞는 템플릿을 선택하며, 파일을 직접 편집해 형식을 커스터마이즈하거나 새 템플릿 파일을 추가할 수 있습니다.

| 파일 | 문제 형식 |
|------|-----------|
| `short-answer.md` | 주관식 (서술형) |
| `multiple-choice.md` | 객관식 (A/B/C/D) |
| `true-false.md` | OX 퀴즈 |
| `fill-in-the-blank.md` | 빈칸 채우기 |

각 문제에는 **내 풀이/내 선택/내 답** 공간이 포함되어 있어 직접 풀어볼 수 있습니다.

## 출력 결과

실행하면 `quiz-output/` 아래에 날짜+시간 폴더가 생성됩니다.

```
quiz-output/
└── 20260316_143022/
    ├── quiz.md       ← 문제지 (정답 없음, 내 풀이 공간 포함)
    └── answers.md    ← 해답지 (문제 + 정답 + 해설)
```

### quiz.md 예시

```markdown
# 말랑말랑 퀴즈 📝

**날짜:** 2026-03-17
**문제 수:** 5문제

---

## Q1. 🟡 보통

빈칸을 채우시오.

TCP에서 수신 버퍼가 가득 차면 송신 측의 `___`가 블로킹되고,
UDP에서는 초과 데이터가 `___`된다.

> **출처:** `server/game_server/3/2026-02-03-game_server_3_5.md`

**📝 내 답:** (빈칸 수에 맞게 작성하세요)

---

## Q2. 🟢 쉬움

다음 중 유니티/언리얼 엔진에 기본 내장된 네트워크 엔진은?

- A. 프라우드넷
- B. 포톤 서버
- C. 게임 스파크
- D. 락넷

> **출처:** `server/game_server/6/2026-02-18-game_server_6_1.md`

**📝 내 선택:** (  )

---

## Q3. 🔴 어려움 · 📌 오답노트 (2번째 복습)

TCP 흐름 제어에서 수신 윈도우 크기가 0이 되면 송신 측은 어떻게 동작하는가?

> **출처:** `server/game_server/3/2026-02-03-game_server_3_5.md`
> **오답노트:** `wn-3f9a2b1c` · 2026-08-19 최초 오답 · 이번이 2번째 복습

**📝 내 답:** (답을 작성하세요)

---
```

`📌 오답노트` 배지가 붙은 문제는 예전에 틀렸던 개념을 다른 문구로 다시 물어보는 문제입니다. 자세한 내용은 [오답노트](#오답노트-복습-재출제) 참고.

## 이미지 지원

마크다운 내 이미지가 있으면 퀴즈 생성에 함께 활용됩니다.

- 이미지는 `.quiz-cache/images/`에 다운로드되어 AI가 내용을 파악하는 데 사용됩니다.
- 결과 마크다운에서는 원본 URL/경로를 그대로 참조합니다. (로컬 복사 없음)
- 파일명 충돌 방지를 위해 캐시 파일명에 해시 prefix 적용 (`abc123_image.png`)

## 프로젝트 구조

```
MallangQuiz/
├── .claude/
│   └── commands/
│       ├── quiz.md              # /quiz 슬래시 커맨드 정의
│       ├── grade.md             # /grade 슬래시 커맨드 정의 (채점)
│       ├── clear-cache.md       # /clear-cache 슬래시 커맨드
│       └── clear-output.md      # /clear-output 슬래시 커맨드
├── quiz-templates/
│   ├── short-answer.md          # 주관식 템플릿
│   ├── multiple-choice.md       # 객관식 템플릿
│   ├── true-false.md            # OX 퀴즈 템플릿
│   └── fill-in-the-blank.md     # 빈칸 채우기 템플릿
├── scripts/
│   ├── collect.js               # 포스트 스캔 + 이미지 수집
│   ├── prepare-grade.js         # 문제지 탐색 + 해답지 매칭 + 답안 추출
│   └── wrongnote.js             # 오답노트 저장소 읽기/쓰기 (pick / record)
├── docs/
│   └── wrong-note-plan.md       # 오답노트 시스템 설계 문서
├── .quiz-wrongnote/
│   └── wrongnotes.json          # 오답노트 저장소 (실행하면 생성됨)
├── mallang-quiz.config.json     # 설정 파일
└── package.json
```
